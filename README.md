### 🤖 Projects

🦿 **[rl_unitree_go2](https://github.com/melvynhuynh/rl_unitree_go2)** - for the Legged Robots course at EPFL, trained velocity-tracking locomotion policies for the Unitree Go2 with PPO in MuJoCo, including stair climbing with a height scan, curriculum learning and domain randomization

🚁 **[sim2real-drone](https://github.com/melvynhuynh/sim2real-drone)** - for the Aerial Robotics course at EPFL, deployed autonomous flight algorithms on Crazyflie drones, from Webots simulation to real flights

🦾 **[ARM-SOFT-Grasping](https://github.com/N-Pulse/ARM-SOFT-Grasping)** - for the N-Pulse association, trained a YOLO26s object detector on Open Images for the computer vision pipeline of a prosthetic arm, for deployment on Arduino UNO Q

🗑️ **[Wall-E-robot-sanitation-worker](https://github.com/melvynhuynh/Wall-E-robot-sanitation-worker-)** - autonomous robot that detects and removes waste in a bounded environment using real-time sensing and control

🧭 **[thymio-ros2-project](https://github.com/melvynhuynh/thymio-ros2-project)** - autonomous navigation on the Thymio robot with ROS 2
